Инструкция по установке:

1) Установите node js

2) Зайдите в терминал и напишите:
```
cd /папка/проекта
npm install --legacy-peer-deps
```

Инструкция по запуску:

1) Зайдите в терминал и напишите:
```
cd /папка/проекта
npm start
```
