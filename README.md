# The Omniscience

> Рабочий стол «второго уровня». Среда поверх среды. **Только Linux.**

The Omniscience — это DE (Desktop Environment) для Linux, которое живёт
поверх другого DE или оконной системы. Оно не борется с хост-системой, не
пытается её заменить — оно даёт тебе **ещё один слой возможностей** сверху
и работает **вместе** с композитором хоста (KWin, Mutter, Openbox).

Обычная программа. Запускается из терминала. Открывает окна, рисует фон,
держит несколько рабочих столов, даёт писать под себя свои приложения.
**Управляет чужими окнами Linux** — рядом с собственными.

С недавнего времени — **полноценная сессия для LightDM**, которую можно
выбрать на экране входа наравне с GNOME, KDE или MATE.

---

## Что внутри

- **Оконный менеджер на Electron + React.** Каждое своё окно — это
  нативный `WebContentsView` с собственным preload. Не iframe, не
  `<webview>`, не имитация. Настоящая изолированная страница.

- **Управление нативными окнами Linux.** Omniscience видит все X11-окна
  системы через EWMH и умеет с ними работать: фокус, перемещение, ресайз,
  максимизация, сворачивание, закрытие. Firefox, терминал, любая
  программа — рядом с твоими приложениями в одном таскбаре.

- **Единый TopBar.** Одна компактная полоса сверху содержит:
  - **крестовину управления** активным окном (перетаскивание, 8 направлений
    ресайза, кнопки окна, поиск/DevTools),
  - **переключатель рабочих столов**,
  - **таскбар** — единый список всех окон: своих и нативных,
  - **ручку перетаскивания** всего окна DE.

- **Таскбар — единый пульт.** Клик по окну = фокус. Больше ничего.
  Случайные клики по самим окнам фокус не меняют.

- **Вкладки меню — тоже приложения.** Список приложений, настройки,
  поиск — всё это `componentapps`, такие же, как любое, что ты напишешь
  сам.

- **Мост состояний** через IPC: любое приложение может читать state
  системы и дёргать её экшены. Никаких whitelist'ов и «разрешённых
  списков» — только то, что ты сам решишь использовать.

- **Встроенная консоль разработчика.** React DevTools и Chromium DevTools
  можно открыть прямо для любого окна — отдельной кнопкой в крестовине.

- **Окно всегда внизу.** В режиме сессии Omniscience регистрируется в X11
  как окно типа `desktop` — оно всегда рендерится под всеми нативными
  окнами системы. Твои приложения и чужие окна ходят поверх него.

- **Все новые окна — внутри Omniscience.** Клик по ссылке с
  `target="_blank"` или `window.open()` из браузерного приложения не
  создаёт чужое нативное окно, а открывает новое окно Omniscience.
  Работает как для Яндекс/Google, так и для любого сайта.

- **Рекурсивность.** Omniscience можно запустить как программу **внутри
  другой сессии Omniscience**. Верхний уровень работает в режиме сессии
  (`type: 'desktop'`), нижний — как обычное окно. Управление работает
  на обоих уровнях независимо.

- Несколько рабочих столов, фон на выбор (картинка, видео, iframe,
  сплошной цвет, свой React-компонент).

## Требования

- **Linux** с X11. Wayland не поддерживается напрямую — только через
  XWayland в X11-сессии.
- **Node.js** для сборки и запуска.
- Для **режима сессии**: `kwin_x11`, `dbus`, `xrandr`, `wmctrl`, `xdotool`,
  `kglobalacceld`, `setxkbmap`, `xsettingsd`. Установщик поставит всё сам.

Omniscience **не работает на Windows и macOS**. Это осознанное решение:
управление чужими окнами на уровне EWMH — linux-only возможность, и вся
архитектура строится именно вокруг неё.

## Установка

### Как обычная программа

```bash
cd /путь/к/проекту
npm install
npm start
```

Это режим «DE поверх DE»: окно внутри твоего текущего рабочего стола.
Управления нативными окнами нет — только свои. Горячие клавиши хоста
продолжают работать.

### Как системная сессия (рекомендуется)

Полноценная сессия на чистом X11 — прямо из меню входа LightDM, рядом с
GNOME, KDE и MATE. Включает **все** возможности: управление нативными
окнами, горячие клавиши, авто-частоту монитора.

**Что делает установщик:**

- Ставит **`kwin_x11`** — нативный композитор KDE, но **без Plasma**.
  Только композитор, никаких панелей, обоев, activities.
- Настраивает KWin без декораций окон — Omniscience рисует свои.
- Ставит **`wmctrl`** и **`xdotool`** — через них управляет чужими окнами.
- Регистрирует **горячие клавиши** через `kglobalacceld`.
- Включает **автоматическое определение частоты монитора** и выставляет
  максимум, который поддерживает железо: 60 Hz, 144 Hz, 240 Hz.
- Резервирует **72px сверху** через `_NET_WM_STRUT_PARTIAL`, чтобы
  нативные окна не перекрывали панель.
- Регистрирует сессию в `/usr/share/xsessions/`.

**Установка:**

```bash
cd /путь/к/проекту
chmod +x install-omniscience-session.sh
./install-omniscience-session.sh
```

Скрипт спросит, ставить ли сочетания клавиш (по умолчанию — да). Затем
выйдите из сессии, на экране входа выберите **Omniscience** — и войдите.

**Поддерживаемые дистрибутивы:** Debian, Ubuntu, Parrot, Kali, Linux Mint,
Pop!_OS, Arch, Manjaro, EndeavourOS, Garuda, Fedora, RHEL, CentOS,
openSUSE, Void, Alpine, Gentoo (в теории).

Для остальных — установите пакеты вручную и запустите скрипт с флагом
`--skip-packages`.

**Если что-то не работает:** смотрите `/tmp/omniscience-error.log`. Все
ошибки и логи стекаются в терминал запуска — там видно, что именно падает.

## Как написать своё первое приложение

Создай папку внутри `componentapps/` — например, `componentapps/hello/`.
Достаточно двух файлов:

**`componentapps/hello/Index.jsx`** — точка входа:

```jsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.jsx';

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

**`componentapps/hello/App.jsx`** — само приложение:

```jsx
import React from 'react';
import { viewDispatch, useViewSetting } from '@viewRuntime';

export default function App() {
  const desktops = useViewSetting('desktops'); // любой срез системного state

  return (
    <div style={{ color: 'white', padding: 20 }}>
      <h2>Hello, Omniscience</h2>
      <button onClick={() => viewDispatch('openOverview', { desktopId: '...' })}>
        Открыть меню
      </button>
    </div>
  );
}
```

Пересобери проект — приложение появится в списке.

**Что ещё можно положить в папку приложения:**

- `ipc.js` — обработчики `ipcMain.handle(...)`, регистрируются автоматически.
- `preload.js` — мост из main-процесса в твой view.
- `index.html` — если нужен свой HTML вместо автоматически сгенерированного.

Всё, что лежит в папке, собирается как отдельное приложение — Vite
подхватит автоматически.

## Производительность

Omniscience **не борется за ресурсы системы**. В типичном сценарии
использования:

- **CPU:** почти ноль. Load average при восьми ядрах — около 1.
- **RAM:** сам DE ~500–700 МБ. Каждое окно — небольшой отдельный процесс.
- **Композитор KWin:** ~200 МБ. Меньше, чем вкладка браузера.
- **FPS:** ровно столько, сколько поддерживает монитор. 60, 120, 144, 240 —
  что железо умеет, то и выдаёт.

Никаких фоновых демонов, индексаторов, телеметрии и «умных» сервисов.
Автозагрузка системы **полностью отключена** — всё, что нужно, запускает
скрипт сессии, и ничего лишнего.
