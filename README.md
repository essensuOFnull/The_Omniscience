# The Omniscience

> Рабочий стол «второго уровня». Не замена ОС — среда поверх среды.

The Omniscience — это DE (Desktop Environment), которое живёт поверх другого
DE или оконной системы. Оно не борется с хост-системой, не пытается её
заменить — оно просто даёт тебе **ещё один слой возможностей** сверху.

Обычная программа. Запускается из терминала. Открывает окна, рисует фон,
держит несколько рабочих столов, даёт писать под себя свои приложения.

С недавнего времени — **полноценная сессия для LightDM**, которую можно
выбрать на экране входа наравне с GNOME, KDE или MATE.

---

## Что внутри

- Оконный менеджер на **Electron + React**.
- Каждое окно — это **нативный `WebContentsView`** с собственным preload.
  Не iframe, не `<webview>`, не имитация. Настоящая изолированная страница.
- Вкладки меню — тоже приложения. Список приложений, настройки, поиск —
  всё это `componentapps`, такие же, как любое, что ты напишешь сам.
- **Мост состояний** через IPC: любое приложение может читать state системы
  и дёргать её экшены. Никаких whitelist'ов и «разрешённых списков» —
  только то, что ты сам решишь использовать.
- **Своя панель управления** для каждого окна — плавающая, со своей сеткой
  кнопок: перетаскивание, ресайз, поиск, браузерный режим, кнопка открытия
  консоли разработчика.
- **Одна глобальная панель** для всего DE — она управляет активным окном,
  перемещается свободно, всегда поверх, скрывается кнопкой в таскбаре.
- **Таскбар** — единый пульт управления. Клик по окну = фокус. Больше
  ничего. Случайные клики по окнам фокус не меняют.
- **React DevTools и Chromium DevTools** встроены внутрь — можно открыть
  консоль разработчика прямо для любого окна.
- Несколько рабочих столов (десктопов), переключение, добавление, удаление.
- Фон рабочего стола — картинка, видео, iframe, сплошной цвет или твой
  собственный React-компонент.
- Настройки темы, анимации окон, и всё это можно менять вживую.

## Установка

### Как обычная программа

1. Установите [Node.js](https://nodejs.org/).
2. В терминале:

```bash
cd /путь/к/проекту
npm install --legacy-peer-deps
npm start
```

### Как системная сессия (рекомендуется)

Omniscience умеет запускаться как **полноценная сессия на чистом X11** —
прямо из меню входа LightDM, рядом с GNOME, KDE и MATE. Это самый
производительный и стабильный способ использования.

**Что делает установщик:**

- Ставит **`kwin_x11`** — нативный композитор KDE, но **без всей Plasma**.
  Только композитор, никаких панелей, обоев, activities.
- Настраивает KWin без декораций окон — Omniscience рисует свои.
- Включает **автоматическое определение частоты монитора** и выставляет
  максимум, который поддерживает железо: 60 Hz, 144 Hz, 240 Hz — что
  угодно. Никаких хардкодов.
- Регистрирует сессию в `/usr/share/xsessions/` — она появится в меню
  выбора сессии на экране входа.

**Установка:**

```bash
cd /путь/к/проекту
chmod +x install-omniscience-session.sh
./install-omniscience-session.sh
```

Затем выйдите из текущей сессии, на экране входа выберите **Omniscience** —
и войдите.

**Поддерживаемые дистрибутивы:** Debian, Ubuntu, Parrot, Kali, Linux Mint,
Pop!_OS, Arch, Manjaro, EndeavourOS, Garuda, Fedora, RHEL, CentOS,
openSUSE, Void. Для остальных — установите `kwin`, `dbus` и `xrandr`
вручную и запустите скрипт с флагом `--skip-packages`.

**Если что-то не работает:** смотрите `/tmp/omniscience-error.log`. Все
ошибки и логи также стекаются в терминал запуска — там видно, что именно
падает.

## Как написать своё первое приложение

Создай папку внутри `componentapps/` — например, `componentapps/hello/`.
Достаточно двух файлов:

**`componentapps/hello/Index.jsx`** — точка входа:

```jsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.jsx';

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

**`componentapps/hello/App.jsx`** — само приложение:

```jsx
import React from 'react';
import { viewDispatch, useViewSetting } from '@viewRuntime';

export default function App() {
  const tab = useViewSetting('desktops'); // любой срез системного state

  return (
    <div style={{ color: 'white', padding: 20 }}>
      <h2>Hello, Omniscience</h2>
      <button onClick={() => viewDispatch('openOverview', { desktopId: '...' })}>
        Открыть меню
      </button>
    </div>
  );
}
```

Пересобери проект — приложение появится в списке.

**Что ещё можно положить в папку приложения:**

- `ipc.js` — обработчики `ipcMain.handle(...)`, регистрируются автоматически.
- `preload.js` — мост из main-процесса в твой view.
- `index.html` — если нужен свой HTML вместо автоматически сгенерированного.

Всё, что лежит в папке, собирается как отдельное приложение — Vite
подхватит автоматически.

## Производительность

Omniscience **не борется за ресурсы системы**. В типичном сценарии
использования (несколько окон, панель управления, DevTools закрыты):

- **CPU:** почти ноль. Load average при восьми ядрах — около 1.
- **RAM:** сам DE ~500–700 МБ. Каждое окно — небольшой отдельный процесс.
- **Композитор KWin:** ~200 МБ. Меньше, чем вкладка браузера.
- **FPS:** ровно столько, сколько поддерживает монитор. 60, 120, 144, 240 —
  что железо умеет, то и выдаёт.

Никаких фоновых демонов, индексаторов, телеметрии и «умных» сервисов,
которые жрут ресурсы в простое. Только окна, панель и то, что ты сам
запустил.
